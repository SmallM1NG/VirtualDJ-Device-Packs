# 本仓库是我整理收集的一些 **VirtualDJ Device Pack**

## 📦 安装说明

**① 查找设备**

在仓库中找到与你的设备型号对应的文件夹，每个设备文件夹内通常包含 **3 个文件**。

**② 下载文件**

完整下载所需的设备文件夹，**保留原始文件夹名称及内部文件结构**，请勿重命名或单独提取文件。

**③ 放置文件**

根据你使用的 VirtualDJ 版本，找到对应的数据目录，将下载的整个设备文件夹放入 `Devices` 文件夹中即可使用。

## 📁 文件夹结构示例

**仓库中的设备文件夹：**

```text
VirtualDJ-Device-Pack/
├── Pioneer-DDJ-XXX/
│   ├── 文件 1
│   ├── 文件 2
│   └── 文件 3
│
├── Numark-XXX/
│   ├── 文件 1
│   ├── 文件 2
│   └── 文件 3
│
└── Denon-XXX/
    ├── 文件 1
    ├── 文件 2
    └── 文件 3
```

**安装到 VirtualDJ 后：**

```text
VirtualDJ/
└── Devices/
    └── Pioneer-DDJ-XXX/
        ├── 文件 1
        ├── 文件 2
        └── 文件 3
```

> 💡 **注意事项**
>
> - 保留设备文件夹的原始名称。
> - 不要修改或删除文件夹内的文件。
> - 请将整个设备文件夹放入 `Devices` 目录，而不是仅复制内部文件。
> - 不同 VirtualDJ 版本的数据目录位置可能不同，请以实际安装环境为准。
